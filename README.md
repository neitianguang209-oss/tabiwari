# たびわり

旅行の立て替えを記録して、最後にぴったり精算する割り勘アプリ（PWA）。
「スーパーの買い出しに個人の買い物が混ざる」「レストランで注文がバラバラ」を、均さずに正しく分けられるのが特徴。

公開URL: https://neitianguang209-oss.github.io/tabiwari/

## できること

- **みんなで共有**：旅ごとのリンクをLINEで送るだけ。ログイン不要で、開いた人が名前を選べばすぐ記録・閲覧できる
- **3つの分け方**
  - 均等に（比率もつけられる：子どもは×0.5、よく飲む人は×1.5 など）
  - 内訳で：行ごとに「だれの分か」を選ぶ。選ばない行は「みんな」で割る（スーパーで個人の物だけ抜く／レストランで品目ごとに振り分け）
  - 一人ずつ：各自が頼んだ額を入れ、残り（シェアした料理・税）はみんなで
  - 合計と内訳の差（税・サービス料・割引）は「頼んだ額に比例」か「みんなで均等」を選べる
- **レシートAI**：撮るとGemini（無料枠）が品目・金額・税・種類を読み取り、タップで振り分けるだけ。外国語のレシートは日本語訳つき。レシートの合計と品目の合計が合っているかも自動で検算
- **一部の人だけ参加**：記録ごとに割る人を選べる。メンバーに参加期間を入れておくと、その日の記録では最初から外れる
- **海外旅行**：外貨で記録して円で精算。レートは無料APIから自動取得（手入力も可）。カード払いは明細の円額を入れればそちらを優先
- **複数人で払った**（ホテル代を2人で半分ずつ、など）
- **精算**：送金回数が最少になる組み合わせを計算（14人までは厳密解）。1人にまとめる方式、10円・100円単位の丸めも。「払った」を押すと記録され、残りが減っていく。LINEに送る文面も自動作成
- **ひとりずつの内訳**：その人の負担が「なぜこの金額か」を1件ずつ表示
- **オフラインOK**：電波がなくても記録でき、つながったら自動で送信。ほかの人の変更はリアルタイムで反映
- **CSV・バックアップ**：Excelで開けるCSV、JSONバックアップと復元

## 仕組み

- React 18 + htm（CDN / esm.sh、ビルド不要）＋ Supabase（既存プロジェクト `gzayrjlhruhvklsidraw` に相乗り、テーブルは `tabiwari_` 接頭辞）
- テーブルは公開キーから直接読めないよう閉じてあり、旅のID（16文字のランダム値）を知っている人だけが関数 `tabiwari_pull` / `tabiwari_push_batch` 経由で読み書きできる
- 金額はすべて最小単位の整数。端数は最大剰余法で配り、合計は必ず支払額ぴったり
- Edge Function `tabiwari`：レシートの読み取り。Geminiのキーはサーバー側（`tabiwari_secret`）にだけ保存。旅ごとに1日60回まで

| ファイル | 役割 |
|---|---|
| `src/lib/split.js` | 割り勘・換算・精算の計算（純粋関数。`tests.html` でテスト） |
| `src/lib/store.js` | 端末保存（IndexedDB）・送信待ち・差分同期・リアルタイム・復元 |
| `src/lib/money.js` | 通貨・金額の変換、為替レート取得 |
| `src/lib/report.js` | LINE用の精算文面、CSV、負担額の説明 |
| `src/ui/ExpenseEditor.js` | 記録の入力（分け方・レシートAI・外貨・複数人払い） |
| `src/ui/Settle.js` | 精算プラン・送金の記録 |
| `supabase/schema.sql` | テーブル・関数一式 |
| `supabase/functions/tabiwari/index.ts` | レシート読み取りの Edge Function |

## データを失わないために

- 記録は各メンバーの端末（IndexedDB）とクラウドの両方にある
- クラウドから旅が消えても、端末に記録が残っていれば自動でクラウドを復元する（端末側を消すことはしない）
- 削除は「削除した印」を付けるだけ（元に戻せる）
- 週次バックアップ（`C:\Users\ひかる\.claude\backup-supabase.ps1`）が `tabiwari_backup_dump` で全件を書き出す（合言葉は同じフォルダの `tabiwari-backup-token.txt`）

## ローカルで動かす

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:5508 を開く。計算のテストは http://localhost:5508/tests.html

## 更新するとき

アプリのファイルを直したら、`sw.js` の `CACHE_NAME` の番号を1つ上げてから push する（上げないと古い画面が出続ける）。
